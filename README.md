# Rock-Paper-Scissors
A simple **Rock–Paper–Scissors** web game built with **JavaScript**, **HTML**, and **CSS**.
Players compete against the computer, with real-time score tracking and responsive UI updates.

## Features
- Interactive gameplay against a computer opponent
- DOM manipulation to update results and score dynamically
- Clean, beginner-friendly code structure
- Event-driven logic handling user selections

## Tech Stack
- JavaScript – game logic & event handling
- HTML – structure
- CSS – styling & layout

## How to Play

1. Open index.html in your browser.
2. Click Rock, Paper, or Scissors.
3. The computer selects at random.
4. Results and score are shown instantly.
